# MiCarrera - TP Final (Visualización e Interfaces 2026)

Carpeta con los documentos a entregar que no forman parte del sitio. El sitio (HTML, CSS y JS originales) está en la raíz del proyecto.

## Contenido

| Archivo | Qué es |
|---|---|
| `MiCarrera_TP_Final.pdf` | Toda la parte teórica unificada (portada, índice, brief, competencia, referencias, wireframes, flujo y capturas) para lectura corrida |
| `BRIEF_MiCarrera.docx` | Brief del servicio (7 puntos de la consigna) |
| `ANALISIS_COMPETENCIA_MiCarrera.docx` | Análisis de competencia |
| `REFERENCIAS_VISUALES.docx` | Referencias visuales y sistema visual final |
| `WIREFRAMES_MiCarrera.docx` | Wireframes, flujo de usuario y capturas del diseño final |
| `capturas/` | Capturas .jpg de las interfaces (desktop y móvil), foto de los wireframes y flujo de usuario |

## Originales de la interfaz (raíz del proyecto)

`index.html`, `favoritos.html`, `login.html`, `404.html` y `assets/` (CSS y JS).

## Pantallas

Home, Resultados, Detalle, Favoritos, Comparación (gráfico) e Ingresar / Crear cuenta (formulario con errores y alerta al guardar sin sesión) y Error 404.
